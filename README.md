## 💻 About This Portfolio Repository

This repository contains the source code for my interactive personal portfolio website.

```text
portfolio/
├── dist/                   # Production build outputs (npm run build)
├── public/                 # Certificate PDFs, project images & icons
├── src/
│   ├── components/         # Reusable React components
│   │   ├── DecryptedText.jsx   # Matrix text scramble effect
│   │   ├── RotatingText.jsx    # Text rotation spring animation
│   │   ├── CertificatesSection.jsx
│   │   └── ProjectsSection.jsx
│   ├── App.jsx             # React root component
│   └── main.jsx            # Entry DOM mounting
├── index.html              # HTML structure & meta SEO
├── style.css               # Design system, tokens & dark styling
├── script.js               # Physics, cursor glow, theme & interactions
├── netlify.toml            # Netlify deployment configuration
├── vercel.json             # Vercel deployment configuration
└── vite.config.js          # Vite build config
```

### Quick Run Instructions
```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build
```

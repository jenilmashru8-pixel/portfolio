A modern, high-performance personal portfolio built for **Jenil Mashru** — Full-stack & AI-ML Developer. Designed with sleek dark UI aesthetic, subtle noise & grid overlays, custom physics interactive components, and smooth animations.

---

## ✨ Features

- ⚡ **Blazing Fast**: Powered by **Vite** and **React 19** for instant HMR and optimized production bundles.
- 🎨 **Sleek & Modern UI**: Tailored typography, soft radial glow cursor effects, and seamless Dark/Light theme switching.
- 🔠 **Interactive Text Effects**: Custom `<DecryptedText />` matrix scrambling effects and dynamic `<RotatingText />` spring animations.
- 💼 **Comprehensive Showcase**:
  - **Tech Stack**: Frontend, Backend, Databases, and Developer Tools.
  - **Experience & Education**: Timeline of professional background and academics.
  - **Certificates & Awards**: Interactive modal viewer for verifying certifications.
  - **Featured Projects**: Highlights of key web and software projects with live/code links.
  - **Contact Section**: Direct outreach form and social profiles.
- 📱 **Fully Responsive**: Flawless experience across mobile, tablet, and desktop screens.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/jenilmashru8-pixel/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

### 5. Preview production build locally
```bash
npm run preview
```

## 📁 Folder Structure

```text
portfolio/
├── dist/                   # Production build directory (generated by npm run build)
├── public/                 # Static assets (images, certificates, icons)
├── src/
│   ├── components/         # Reusable React components
│   │   ├── DecryptedText.jsx   # Decrypted text scrambling effect component
│   │   ├── RotatingText.jsx    # Text rotation spring animation component
│   │   ├── CertificatesSection.jsx
│   │   └── ProjectsSection.jsx
│   ├── App.jsx             # Main React entry component
│   └── main.jsx            # React DOM root
├── index.html              # Main HTML entry point
├── style.css               # Design system, tokens & global styling
├── script.js               # Physics, cursor glow, theme & UI interactions
├── netlify.toml            # Netlify deployment configuration
├── vite.config.js          # Vite build config
├── vercel.json             # Vercel deployment configuration
└── package.json            # Dependencies and scripts
```
